# Candidate decision, 17 November 2026

Selected: LinearB, engineering-delivery-analytics. No existing build in this registry has that family. This is distinct from tonight's legal transaction closing and field inspection review builds. The base handles delivery records and measurement, not project portfolio planning, release announcements or incident case management.

Annual price scenario: US$17,400 for 50 Essentials users at US$29 per user per month, billed annually. [Vendor pricing](https://linearb.io/pricing) describes Essentials for teams with 50 or more developers and Enterprise at US$59 per user per month for teams with 100 or more. The scenario is arithmetic from the published rate, not an invoice, quote, minimum commitment assertion or confirmed NZ/AU customer spend. Additional usage, service and integration costs are not included.

[Swarmia pricing](https://www.swarmia.com/pricing/) shows Enterprise at US$55 per developer per month billed annually, a US$33,000 scenario at 50 developers. Its [Code Overview CSV announcement](https://www.swarmia.com/changelog/2023-01-31-review-nudges-and-automated-change-failure-detection/) establishes an export, but the LinearB dashboard layout is documented more explicitly. Both are the same candidate family. Swarmia is research context, not another queued build.

The bill score uses 2 for the documented ten-to-twenty-thousand range. No named buyer or invoice was found in local customer or CRM-related files. Live CRM was not queried; buyer evidence is therefore 1, not inferred from the existence of software customers. Search scores are qualitative: [G2's alternatives page](https://www.g2.com/products/linearb/competitors/alternatives) and current pricing comparison results demonstrate an active comparison surface, not measured search volume.

Waydev was considered but not ranked without a verified public annual bill. Orderful was rejected because the trading-partner network and connectivity are core to its offer. Filestage was rejected for this run because visual proofing would make an interactive front end central. Recruitment tools were excluded under the charter.

[LinearB's export guide](https://linearb.helpdocs.io/article/12miefwqfm-how-can-i-share-my-linear-b-metrics) documents one metric widget per CSV column and one date range per row. It does not promise a single fixed header set or underlying raw events. The importer therefore takes an explicit field and units map, preserving the raw data rather than guessing it.

The free base is an offline delivery record and review system. Connections and platform automation need separate implementation. No exclusive feature or incumbent inability is asserted: the ten questions are questions this build demonstrably answers, including its own custom policy and action records.
