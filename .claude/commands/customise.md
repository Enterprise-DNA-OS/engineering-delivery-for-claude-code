# Customise the delivery system

Read CLAUDE.md, the migration, docs/metrics.md and the relevant command. Turn the requested field or rule change into a new numbered migration under supabase/migrations/. Preserve existing records. Update the CLI, reports, documentation and meaningful smoke checks together. Run npm run migrate, npm test and the affected command. Present the resulting record or report. Do not edit an applied migration or silently alter measurement definitions. Deletions and external actions require the operator's explicit instruction.
