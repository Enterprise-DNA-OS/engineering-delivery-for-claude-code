# Add a read-only view

Read views.json and the existing database views. Add a uniquely named report using SELECT queries over the records, with clear labels, units, sample counts and unknown values. Keep every query read-only. Run npm run view -- <name>, inspect the generated HTML at desktop and mobile widths, and present the file. Do not add buttons that write or an application front end.
