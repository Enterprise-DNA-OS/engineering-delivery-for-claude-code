# dora

Read docs/metrics.md. State the inclusive start and exclusive end, the service, sample counts, unresolved failures and unknown values. Never rank people or compare unlike services.

```bash
npm run delivery -- dora
```

Examples use fictional names and dates. Substitute verified values before writing. Supported flags: --from, --to. Use --json for structured output. Writes require --actor. Ambiguous names list candidates and stop. Never send, publish, delete or infer a record that is not present.
